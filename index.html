Sobre esta base de datos

Este repositorio reúne los datos estructurales y antigénicos generados en la tesis de maestría en inmunología del Instituto de Investigaciones Inmunológicas de la Universidad de Cartagena. Incluye modelos 3D pre y post-dinámica molecular, predicciones de epítopes B lineales y conformacionales, epítopes T para alelos HLA frecuentes en población colombiana, y datos de interacción con IgE. Está diseñado para acumular nuevas proteínas caracterizadas con la misma metodología y servir como base de entrenamiento de modelos de inteligencia artificial institucionales.

Protocolo metodológico

Ruta replicable para la caracterización estructural y antigénica de nuevas proteínas alergénicas. Cada paso genera archivos que se agregan a esta base de datos.

1

Secuencia y modificaciones post-traduccionales

Obtención de la secuencia FASTA desde GenBank o UniProt. Predicción de PTMs y puentes disulfuro. Análisis del índice antigénico (Jameson-Wolf).

MusiteDeepDisulfide by Design 2.0Protean3D
2

Modelado y validación estructural 3D

Generación de modelos tridimensionales con y sin plantillas. Validación de calidad estereoquímica. Selección del mejor modelo.

ColabFoldSwissModelo.MolProbityProSAwebEvoEF2UCSF Chimera
3

Simulación de dinámica molecular

Simulaciones de 400 ns en agua explícita. Análisis de RMSD, RMSF, radio de giro y SASA. Refinamiento del modelo estructural.

AmberToolCpptrajXmgrace
4

Predicción de epítopes B lineales

Predicción con umbral de confianza moderada (top 50%) y alta (top 20%). Comparación con epítopes reportados en bases de datos.

BepiPred 3.0IEDB
5

Predicción de epítopes B conformacionales

Identificación de residuos superficiales con potencial antigénico. Combinación de herramientas para mayor cobertura.

DiscoTope 3.0Ellipro
6

Predicción de epítopes T CD4+

Ligandos para alelos HLA clase II frecuentes en población colombiana. Clasificación en strong binders (Rank ≤1%) y weak binders (Rank 1-5%).

NetMHCIIpan 4.0IEDB
7

Docking molecular con IgE

Acoplamiento proteína-proteína con la región Fab de IgE humana. Cálculo de energía libre de unión por MM/GBSA. Identificación de parches de interacción.

HawkDockMM/GBSAPDB: 7MLHUCSF Chimera

Cómo usar esta página

Guía paso a paso para publicar esta base de datos en internet y agregar nuevas proteínas.

1. Crear cuenta GitHub

Ve a github.com y crea una cuenta gratuita. GitHub te da hosting gratuito ilimitado para páginas web estáticas.

→ github.com/signup

2. Crear el repositorio

Crea un nuevo repositorio público llamado iii-allergen-db. Activa GitHub Pages en Settings → Pages → Branch: main.

Tu URL: usuario.github.io/iii-allergen-db

3. Subir este archivo

Sube el archivo index.html a la raíz del repositorio. GitHub lo publicará automáticamente como página web.

Raíz/ → index.html

4. Organizar archivos

Crea carpetas para cada proteína. Sube los archivos .pdb, .fasta, .csv en la carpeta correspondiente.

proteins/blo-t-2/model_post.pdb

5. Cargar estructuras 3D

En el código, actualiza la variable pdbFiles con la URL de tu GitHub para que el visualizador cargue los archivos .pdb.

raw.githubusercontent.com/usuario/...

6. Agregar nuevas proteínas

Edita el array epitopesData y filesData en el script de esta página. Sigue el mismo formato para cada nueva proteína.

{ protein: 'Blo t 21', type: 'Lineal', ... }
